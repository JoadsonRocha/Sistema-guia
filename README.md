# Sistema Guia

## Deploy no Railway

### Variáveis de ambiente recomendadas

- PORT=3000
- NODE_ENV=production
- ALLOWED_ORIGINS=https://www.nexuspolitica.com.br,https://nexuspolitica.com.br,http://localhost:3000,http://127.0.0.1:3000
- VITE_SUPABASE_URL
- VITE_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY
- GEMINI_API_KEY
- SENTRY_DSN

### Comandos locais

```bash
npm install
npm run build
npm run start
```
